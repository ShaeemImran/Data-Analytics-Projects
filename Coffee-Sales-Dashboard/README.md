# Coffee Sales Analytics Dashboard
An interactive Excel dashboard analyzing global coffee orders, sales performance, country trends, and top customer contributions across various coffee types and roast profiles.

---

## Business Problem Solved
Evaluated retail coffee revenue streams across multiple countries (USA, UK, Ireland) to identify top-performing product lines, and roast preferences
This enables targeted marketing campaigns and optimized inventory stocking.

---

## Key Technical Workflow
1. **Data Lookup & Integration:** Used `XLOOKUP` to combine customer profiles, product specifications, and transaction logs.
2. **Data Aggregation:** Built PivotTables to track total sales revenue, order volumes, and average order values by roast type and package size.
3. **Interactive Visuals:** Integrated dynamic slicers for Coffee Type, Roast Profile, and Package Size alongside time-series timeline controls.
